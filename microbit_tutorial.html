2 How the Game Works (The DJ Mixing Desk Analogy) 🎛️

Don't worry about the massive, hidden code blocks running on the server — think of your micro:bit as a DJ soundboard. You don't need to know how every single internal chip is soldered together, you just need to mix/manoeuvre the dials!

Your micro:bit controller will map live physics directly to 2 main network parameters:

  1. The Tilt Factor (The Volume Dial): Shaking or tilting your micro:bit changes the gravitational force (acceleration / sudden movement) acting on it. This is measured by the micro:bit's accelerometer - changes in these movements simulate a thread to the rover.
  2. Button A (The Exploit Flag): Pressing this button updates a true/false status variable, signaling a sudden command-line override data injection.

3 Step 1: Programming Your Rover Controller 🕹️

Copy the code layout below and paste it completely into your micro:bit Python editor window. Look closely at the highlighted CHALLENGE ZONE—this is where you will tweak the logic rules!

from microbit import *

# Connects your micro:bit transmission line to the server network link
uart.init(bits_per_second=115200)

# Dashboard boot-up sequence animation
display.show(Image.CHESSBOARD)
sleep(600)
display.clear()

while True:
    # 📊 REGULAR SENSOR SYSTEM (Do Not Alter)
    # Measures how far you roll the board left or right
    raw_tilt = accelerometer.get_x()
    stress_factor = raw_tilt / 1000.0
    
    # 🛠️ ========================================================
    # 🔥 CHALLENGE ZONE: WRITE YOUR PAYLOAD RULES
    # ========================================================
    # Objective: Toggle 'is_hacking' from "False" to "True" when Button A is pressed!
    is_hacking = "False"
    
    if button_a.is_pressed():
        is_hacking = "True"  # This activates your cyber attack signal override!
        
    # ========================================================
    # 📡 DATA TRANSMITTER BLOCK (Do Not Alter)
    # ========================================================
    # Compiles and shoots your parameters down the USB tether line
    payload = "Team_Alpha,{},{:.2f}\n".format(is_hacking, stress_factor)
    uart.write(payload)
    
    # Check if the central laptop's AI Shield returned an interception alert
    if uart.any():
        msg = str(uart.read(), 'UTF-8').strip()
        
        if "ai_caught:True" in msg:
            display.show(Image.SKULL)  # 🚨 Intercepted! The AI model flagged your anomaly.
        else:
            display.show(Image.YES)     # ✅ Verification cleared! Operating safely.
            
    sleep(200)

4 Step 2: Running and Testing Your Code 🚀

Ready to deploy your custom software application? Go through this checklist to mount your firmware:

  1. Hook your micro:bit up to the computer workstation using a micro-USB communication cable.
  2. Select the purple Connect button in your browser editor tool, highlight your device identifier, and click pair.
  3. Click the Flash button. Watch the status LED on the underside of your board blink until complete.
  4. Play the Game: Leave the controller resting completely flat on your desk. You will see a clear verification mark (✅). Now, tilt your board sharply to one side or mash down on Button A. Can you trick the system into showing the security alarm (🚨 SKULL)? If so, your anomaly successfully broke out of normal operational thresholds!

5 Technical Reference: Data Layouts

Here is a quick look at the exact information fields travelling between your controllers and the backend dashboard app.

Inbound Data Packet (Sent from your micro:bit)

Field Name Type What It Controls
team_id Text Logs the name of the cohort station transmitting information.
attack True/False Tells the server if you are attempting an override command injection.
mod_value Decimal The live tilt physical stress measurement read from your accelerometer.

Return Data Packet (Sent back by the central AI Server)

Field Name Type What It Controls
status Text Confirms if the server communication channel is online and stable.
ai_caught True/False Returns True if the AI model flags your physical data sequence as an anomaly.
anomaly_score Decimal The AI safety score. Higher variations mean your patterns look highly abnormal.

6 Live Workshop Troubleshooting Guide

🚨 The micro:bit is flat, but it is showing a permanent SKULL image

Solution: The background adapter link might be paused on your workstation machine. Ask your group mentor to quickly restart the gateway script running on the master computer terminal to flush the active server buffer lines.

⚠️ I am tilting the board and clicking buttons, but the grid stays completely blank

Solution: Your code could be missing a closing loop connection line. Re-verify that the entire while True: script was correctly highlighted and flashed down to the microcontroller from the top web browser compiler tool.
